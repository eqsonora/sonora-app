# Code of Conduct

This is a place to talk about sound and about an app. Keep it useful and kind.

**Welcome here:** questions of any level, honest criticism of the app, ideas
that may never be built, disagreement argued with reasons.

**Not welcome here:** insults, harassment, discrimination of any kind,
sexual content, spam and advertising, and posting anyone's private information.

Criticise the app as hard as you like. Do not attack the people using it or
making it.

## Enforcement

Maintainers may edit, hide or remove posts, lock threads, and block accounts
that break these rules. To report something, use the **Report content** option
on the post, or write privately through GitHub's reporting tools.

This code is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org).
